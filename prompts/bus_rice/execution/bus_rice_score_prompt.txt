→ 决定淀粉类型，糯稻直链淀粉含量低，适于加工特色食品。
播种期：取值数量108，语义复杂
→ 包含时间描述（如“4月中旬”）、区域限定（如“桂南早稻3月10日前”）、农艺建议等。
→ 建议归一化处理为标准时间区间（如“3月上旬”“4月中旬”）或按生态区+季节拆分字段。
谷粒形状：取值数量329，高度异构
→ 包含纯形态描述（如“椭圆”“细长”）、长宽比数值（如“长宽比3.0”）、附加特征（如“无芒”“稃尖紫色”）及混合文本。
→ 建议提取核心语义：① 主形状（椭圆/长粒/圆粒/细长等）；② 长宽比数值；③ 芒/稃尖等附属特征。

→ 多为颜色描述，可归类为“黄色系”主色调，部分含芒信息（如“有芒”），建议分离芒性状。
颖尖色：取值集合 {紫色, 黄白, 秆黄色, 浅黄色, 中等红色, 淡, …}
→ 形态标记性状，常用于品种鉴别，紫色颖尖多与抗性或遗传背景相关。
②【模糊匹配与地点字段】
品种相关字段
模糊匹配（LIKE）：
种质名称：用于用户输入关键词检索（如“中稻”“香稻”）

全国统一编号：唯一标识，必须精确匹配
籼粳亚种、 早中晚稻、 粘糯：分类字段，使用等值筛选
地理字段
原产国：使用精确匹配（=）
→ 如“中国”国家名称标准化后匹配
原产地：使用模糊匹配（LIKE）
→ 支持“广西”“四川”等地域关键词检索


③【综合评分与排序逻辑】
设计三个典型育种目标导向的评分模型，支持科研人员按需筛选。 粘糯 缺失严重
移出 WHERE 硬条件，改为 CASE WHEN 加分项，缺失值赋中性分

模型一：优质食用型水稻种质筛选（侧重米质外观，弱化粘糯依赖）
-- 目标：筛选适合优质米市场的种质，强调长宽比、千粒重、粒长、结实率
-- 改进：粘糯仅作为加分项，不设硬性过滤
SELECT 
    全国统一编号,
    种质名称,
    籼粳亚种,
    早中晚稻,
    谷粒长宽比,
    千粒重,
    粒长,
    结实率,
    粘糯,
    (CASE 
        WHEN 谷粒长宽比 >= 3.0 THEN 30
        WHEN 谷粒长宽比 >= 2.8 THEN 25
        WHEN 谷粒长宽比 >= 2.5 THEN 20
        ELSE 10
     END +
     CASE 
        WHEN 千粒重 BETWEEN 24.0 AND 28.0 THEN 20
        WHEN 千粒重 BETWEEN 22.0 AND 30.0 THEN 10
        ELSE 5
     END +
     CASE 
        WHEN 粒长 >= 6.5 THEN 15
        ELSE 5
     END +
     CASE 
        WHEN 结实率 >= 85.0 THEN 20
        WHEN 结实率 >= 80.0 THEN 15
        ELSE 10
     END +
     CASE 
        WHEN 籼粳亚种 = '籼' THEN 15
        ELSE 5
     END +
     CASE 
        WHEN 粘糯 = '粘' THEN 10  -- 加分项：粘稻更符合主流优质米需求
        WHEN 粘糯 = '糯' THEN 5
        ELSE 8  -- 缺失值给予中性分，避免惩罚
     END) AS total_score
FROM bus_rice_data
WHERE 
    谷粒长宽比 IS NOT NULL
    AND 千粒重 IS NOT NULL
    AND 粒长 IS NOT NULL
    AND 结实率 IS NOT NULL
    AND 谷粒长宽比 >= 2.8
    AND 千粒重 BETWEEN 22.0 AND 30.0
    AND 结实率 >= 75.0
ORDER BY total_score DESC
LIMIT 5;
专业说明：
优质籼稻以细长粒、高长宽比、透明度好为特征。本模型将“粘糯”设为加分项而非门槛，缺失值不导致数据排除，提升查全率，适用于商业品种推荐系统

模型二：高产潜力型水稻种质筛选（聚焦产量三要素，忽略粘糯）
-- 目标：筛选高产潜力材料，聚焦有效穗数、穗粒数、千粒重、结实率
-- 改进：完全不依赖粘糯字段
SELECT 
    全国统一编号,
    种质名称,
    有效穗数,
    穗粒数,
    千粒重,
    结实率,
    全生育期,
    株高,
    (CASE 
        WHEN 有效穗数 >= 20.0 THEN 30
        WHEN 有效穗数 >= 18.0 THEN 25
        WHEN 有效穗数 >= 16.0 THEN 20
        ELSE 10
     END +
     CASE 
        WHEN 穗粒数 >= 200.0 THEN 30
        WHEN 穗粒数 >= 180.0 THEN 25
        WHEN 穗粒数 >= 160.0 THEN 20
        ELSE 10
     END +
     CASE 
        WHEN 千粒重 BETWEEN 26.0 AND 30.0 THEN 20
        WHEN 千粒重 BETWEEN 24.0 AND 32.0 THEN 15
        ELSE 10
     END +
     CASE 
        WHEN 结实率 >= 85.0 THEN 20
        WHEN 结实率 >= 80.0 THEN 15
        ELSE 10
     END +
     CASE 
        WHEN 株高 BETWEEN 90.0 AND 115.0 THEN 10  -- 适中株高利于抗倒高产
        ELSE 5
     END) AS total_score
FROM bus_rice_data
WHERE 
    有效穗数 IS NOT NULL
    AND 穗粒数 IS NOT NULL
    AND 千粒重 IS NOT NULL
    AND 结实率 IS NOT NULL
    AND 有效穗数 >= 16.0
    AND 穗粒数 >= 160.0
    AND 千粒重 BETWEEN 24.0 AND 32.0
    AND 结实率 >= 75.0
ORDER BY total_score DESC
LIMIT 5;
专业说明：
高产育种核心是“三要素协同 + 结实率保障”。本模型完全规避 粘糯 字段，确保即使该字段缺失率高，仍能召回大量有效高产种质，适用于大面积种质资源普查与初筛。 

模型三：早熟适应型水稻种质筛选（适合双季稻或灾后补种）
-- 目标：筛选生育期短、适应性强的早熟型种质
-- 改进：不依赖粘糯，原产地模糊匹配更实用
SELECT 
    全国统一编号,
    种质名称,
    全生育期,
    株高,
    早中晚稻,
    原产地,
    粘糯,
    (CASE 
        WHEN 全生育期 <= 110.0 THEN 40
        WHEN 全生育期 <= 120.0 THEN 35
        WHEN 全生育期 <= 130.0 THEN 30
        ELSE 10
     END +
     CASE 
        WHEN 早中晚稻 = '早' THEN 30
        WHEN 早中晚稻 = '中' THEN 20
        ELSE 10
     END +
     CASE 
        WHEN 株高 BETWEEN 80.0 AND 110.0 THEN 20  -- 抗倒伏适中株高
        ELSE 10
     END +
     CASE 
        WHEN 原产地 LIKE '%华南%' OR 原产地 LIKE '%广西%' 
             OR 原产地 LIKE '%广东%' OR 原产地 LIKE '%福建%' 
             OR 原产地 LIKE '%江西%' OR 原产地 LIKE '%湖南%' THEN 10
        ELSE 5
     END +
     CASE 
        WHEN 粘糯 = '粘' THEN 5   -- 加分：粘稻更适主流早稻市场
        WHEN 粘糯 = '糯' THEN 3
        ELSE 4  -- 缺失值中性处理
     END) AS total_score
FROM bus_rice_data
WHERE 
    全生育期 IS NOT NULL
    AND 全生育期 <= 135.0
    AND 早中晚稻 IN ('早', '中')
    AND 株高 BETWEEN 70.0 AND 120.0
    AND 结实率 IS NOT NULL
    AND 结实率 >= 70.0  -- 早熟品种可适当放宽结实率要求
ORDER BY total_score DESC
LIMIT 5;
专业说明：
早熟品种需在短生育期内完成高产积累。本模型结合熟期、生态区适应性与株型，将“粘糯”作为市场适配性加分项，适用于双季稻区品种推荐或救灾备荒资源库建设。
