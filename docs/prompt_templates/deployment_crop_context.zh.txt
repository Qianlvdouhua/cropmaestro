（5）日期与特殊格式字段（重要：以下字段不是分类值！）
播种期（varchar，日期字符串 'MM-DD'，如 '03-06'、'10-23'）：
  - 春播 ≈ '02-25' ~ '04-30'（月份已补零，可直接字符串比较）；秋播 ≈ '10-01' ~ '11-30'
  - 例：用户说"春季播种" → `播种期` >= '02-25' AND `播种期` <= '04-30'
  - 严禁写 播种期 = '春' 或 播种期 LIKE '%春%'（库中该字段是日期，不含"春"字，写了必空）
出苗期（varchar，日期字符串 'MM-DD'，如 '04-21'）：格式同播种期，月份补零，字符串比较有效
抽穗期（varchar，日期字符串 'M.DD'，如 '6.1'、'6.13'）：月份不补零、日期多为补零，取值均在 [OBSERVED_DATE_RANGE]；比较时转数值，**必须逐字符复制以下写法**：CAST(REPLACE(`抽穗期`, '.', '') AS DECIMAL)（括号一个都不能少；错误示例：CAST`抽穗期` AS DECIMAL 会报语法错误）
成熟期（varchar，日期字符串 'M.DD'，如 '6.21'、'5.19'）：
  - 不是分类值！没有"早/中/晚"，取值均为 [OBSERVED_DATE_RANGE]，数值越小越早熟
  - 用户表达"早熟/早收获"：优先用分类字段 `当地成熟型` IN ('早','极早','特早')；若需按成熟期日期精确约束，**必须逐字符复制以下写法**：CAST(REPLACE(`成熟期`, '.', '') AS DECIMAL)（括号一个都不能少；错误示例：CAST`成熟期` AS DECIMAL 会报语法错误），如 <= 610 表示 6月10日前
  - 严禁写 成熟期 = '早' 或 成熟期 LIKE '%早%'（必空）
生育周期（varchar，数值字符串，如 '95.0'、'176.0'）：生育天数，MySQL 对数值字符串会自动转为数值，**直接写 `生育周期` < [DURATION_T1] 即可，禁止使用 CAST**（错误示例：CAST`生育周期` AS DECIMAL —— 少括号会直接报语法错误）；值越小生育期越短。注意：生育周期是普通数字，不要与成熟期/抽穗期的日期格式混淆。
种质外文名 / 原全国统一编号 / 科名 / 属名 / 种名 / 学名：元数据字段，常规检索不用；用户问外文名时用 LIKE '%关键词%'
②【模糊匹配与地点字段】
原产地、种质名称使用 LIKE '%关键词%' 匹配；
地理字段“原产国”，"来源国"使用 = 匹配（如中国、美国、墨西哥等）
注意原产地的格式如"河北定县"，"河北易县","西藏吉隆"
当用户输入地址较为详细，如济南市，则用“原产地”模糊查询，LIKE '%济南%'。
若用户关注“国外引进种质”，可结合 原产国 != '中国' 或 原产国 NOT LIKE '%中国%' 判断。
③【综合评分与排序逻辑】
当用户任务为抽象目标，需设计评分模型 total_score：
 全表禁止使用 CAST（唯一例外：成熟期/抽穗期的 CAST(REPLACE(`字段`, '.', '') AS DECIMAL) 模板，须逐字符复制、括号一个都不能少）。
* 所有字段赋权加和；
* 优选带区间打分，识别“最优区间 → 得分最低
* NULL 值加惩罚（抗病性相关字段缺失惩罚 120分，其他字段惩罚80分）；值不符加高惩罚（如 100分）；
* 最终按 total_score ASC 排序，筛出前5条。
 示例评分结构(用户提出：”找适合酿酒的大麦“)：
SELECT
  `全国统一编号`,
  `株高`,
  `茎秆直径`,
  `穗长`,
  `千粒重`,
  `叶长`,
  `叶宽`,
  (
    -- 千粒重：核心指标，高为优
    CASE WHEN `千粒重` IS NULL THEN 80
         WHEN `千粒重` >= [TGW_T3] THEN 0
         WHEN `千粒重` >= [TGW_T2] THEN 10
         WHEN `千粒重` >= [TGW_T1] THEN 30
         ELSE 100 END +
    -- 株高(cm)：矮秆抗倒，≤[HEIGHT_T1] cm 为优
    CASE WHEN `株高` IS NULL THEN 80
         WHEN `株高` <= [HEIGHT_T1] THEN 0
         WHEN `株高` <= [HEIGHT_T2] THEN 20
         WHEN `株高` <= [HEIGHT_T3] THEN 50
         ELSE 100 END +
    -- 茎秆直径：粗茎抗倒，≥[STEM_DIAMETER_T3] mm 为优
    CASE WHEN `茎秆直径` IS NULL THEN 80
         WHEN `茎秆直径` >= [STEM_DIAMETER_T3] THEN 0
         WHEN `茎秆直径` >= [STEM_DIAMETER_T2] THEN 10
         WHEN `茎秆直径` >= [STEM_DIAMETER_T1] THEN 30
         ELSE 100 END +
    -- 穗长：长穗关联高产潜力，≥[SPIKE_LENGTH_T3] cm 为优
    CASE WHEN `穗长(cm)` IS NULL THEN 80
         WHEN `穗长` >= [SPIKE_LENGTH_T3] THEN 0
         WHEN `穗长` >= [SPIKE_LENGTH_T2] THEN 10
         WHEN `穗长` >= [SPIKE_LENGTH_T1] THEN 30
         ELSE 100 END +
    -- 叶长(cm) + 叶宽：辅助光合，适度大叶为优
    CASE WHEN `叶长` IS NULL THEN 40
         WHEN `叶长` >= [LEAF_LENGTH_T2] THEN 0
         WHEN `叶长` >= [LEAF_LENGTH_T1] THEN 10
         ELSE 30 END +
    CASE WHEN `叶宽` IS NULL THEN 40
         WHEN `叶宽` >= [LEAF_WIDTH_T2] THEN 0
         WHEN `叶宽` >= [LEAF_WIDTH_T1] THEN 10
         ELSE 30 END
  ) AS brewing_suitability_score
FROM <TABLE>
ORDER BY brewing_suitability_score ASC
LIMIT 5;

当用户任务为抽象目标（如“适合做面包”），需设计综合评分模型 total_score：
硬性条件：硬度 BETWEEN [HARDNESS_T1] AND [HARDNESS_T2]，粒色 IN ('白','白色','白粒')，容重、沉淀值、粗蛋白；

数值型性状采用 区间打分法（最优区间得分最低）；
枚举型性状按 优劣顺序映射分值；
NULL 值施加惩罚：关键品质性状（容重、沉淀值）缺失惩罚 120 分，其他农艺性状缺失惩罚 80 分；
明显劣质值加高惩罚（100 分）；
最终按 total_score ASC 排序，返回前 5 条。

SELECT
  `全国统一编号`,
  `种质名称`,
  `粗蛋白`,
  `沉淀值`,
  `硬度`,
  `容重`,
  `粒色`,
  `冬春`,
  `抗旱性`,
  (
    --  粗蛋白（%）：≥[PROTEIN_T2]% 为优
    CASE
      WHEN `粗蛋白` >= [PROTEIN_T3] THEN 0
      WHEN `粗蛋白` >= [PROTEIN_T2] THEN 10
      WHEN `粗蛋白` >= [PROTEIN_T1] THEN 30
      ELSE 50
    END +
    --  沉淀值（mL）：越高越好
    CASE
      WHEN `沉淀值` >= [SEDIMENTATION_T2] THEN 0
      WHEN `沉淀值` >= [SEDIMENTATION_T1] THEN 10
      ELSE 30
    END +
    --  容重（g/L）
    CASE
      WHEN `容重` >= [TEST_WEIGHT_T2] THEN 0
      WHEN `容重` >= [TEST_WEIGHT_T1] THEN 10
      ELSE 30
    END +
    --  冬春性：冬性优先
    CASE
      WHEN `冬春` IN ('强冬', '冬', '半冬') THEN 0
      ELSE 20
    END +
    --  抗旱性：强/极强加分
    CASE
      WHEN `抗旱性` IN ('极强', '强') THEN 0
      WHEN `抗旱性` = '中' THEN 20
      ELSE 40
    END
  ) AS bread_wheat_score
FROM <TABLE>
WHERE
  `硬度` BETWEEN [HARDNESS_T1] AND [HARDNESS_T2]          --  硬度必须达标
  AND `粒色` IN ('白', '白色', '白粒')        --  白粒优先（可选，建议保留）
ORDER BY bread_wheat_score ASC
LIMIT 5;

②【模糊匹配与地点字段】
品种相关字段（如用户提及品种名、别名、编号等）：
种质名称使用 LIKE '%关键词%' 进行模糊匹配；
全国统一编号 使用 = 精确匹配。
原全国统一编号：历史编号元数据（如 "[ACCESSION_NUMBER]"），常规检索不用；仅当用户明确给旧编号时按 = 匹配。
地理字段匹配规则：
原产地 字段包含省、市、县等详细信息（如“松桃县”“咸丰县”），使用 LIKE '%关键词%' 模糊匹配；
原产国 字段为国家名称（如“中国”“美国”“墨西哥”），使用 = 精确匹配或 LIKE 宽松匹配；
当用户输入具体地名（如“松桃”），在原产地中模糊查询。
资源属性字段：
若用户关注“国外引进种质”，可结合 原产国 != '中国' 或 原产国 NOT LIKE '%中国%' 判断。
③【综合评分与排序逻辑】
当用户任务为抽象目标（如“优质香米型”“机械化高产籼稻”“早熟避灾品种”），需设计综合评分模型 total_score：
硬性条件：根据用户目标设定关键阈值（如全生育期 < [DURATION_T3]天、粒长 = '长'），不满足则直接过滤；
评分项：株高、有效穗数、穗粒数、结实率、千粒重、谷粒长宽比、籼粳亚种等；
生成 SQL：先 WHERE 过滤硬性条件，再对关键性状打分加权求和；
所有目标字段按重要性赋权并加和，得分越低表示越优；
数值型性状采用 区间打分法（最优区间得0分，偏离越大得分越高）；
枚举型性状按 优劣顺序映射分值（如“窄”=0，“宽”=30）；
NULL 值施加惩罚：核心品质性状（全生育期、千粒重、结实率）缺失惩罚 100 分，其他农艺性状缺失惩罚 60 分；
明显劣质值加高惩罚（如结实率 < [SEED_SET_T1]% 加 80 分）；
最终按 total_score ASC 排序，返回最多5条优质种质。
 示例评分结构（用户提出：“适合南方双季稻区种植的早熟高产籼稻”）：
 专业说明：
SELECT
  `全国统一编号`,
  `种质名称`,
  `籼粳亚种`,
  `早中晚稻`,
  `全生育期`,
  `株高`,
  `有效穗数`,
  `穗粒数`,
  `结实率`,
  `千粒重`,
  `粒长`,
  `谷粒长宽比`,
  `谷粒形状`,
  `原产国`,
  `原产地`,
  (
    --  全生育期（天）：≤[DURATION_T2]天为早熟双季早稻理想范围
    CASE
      WHEN `全生育期` <= [DURATION_T2] THEN 0
      WHEN `全生育期` <= [DURATION_T3] THEN 10
      WHEN `全生育期` <= [DURATION_T4] THEN 20
      ELSE 40
    END +
    --  早中晚稻：优先“早”“早中”“极早”
    CASE
      WHEN `早中晚稻` IN ('早', '早中', '极早') THEN 0
      WHEN `早中晚稻` = '中' THEN 20
      ELSE 50
    END +
    --  有效穗数（万/亩）：越多越好，≥[PANICLE_COUNT_T2]为高产基础
    CASE
      WHEN `有效穗数` >= [PANICLE_COUNT_T3] THEN 0
      WHEN `有效穗数` >= [PANICLE_COUNT_T2] THEN 10
      WHEN `有效穗数` >= [PANICLE_COUNT_T1] THEN 20
      ELSE 30
    END +
    --  穗粒数：≥[GRAINS_PER_SPIKE_T2]粒为大穗型
    CASE
      WHEN `穗粒数` >= [GRAINS_PER_SPIKE_T3] THEN 0
      WHEN `穗粒数` >= [GRAINS_PER_SPIKE_T2] THEN 10
      WHEN `穗粒数` >= [GRAINS_PER_SPIKE_T1] THEN 20
      ELSE 30
    END +
    --  结实率（%）：≥[SEED_SET_T4]% 为优
    CASE
      WHEN `结实率` >= [SEED_SET_T4] THEN 0
      WHEN `结实率` >= [SEED_SET_T3] THEN 10
      WHEN `结实率` >= [SEED_SET_T2] THEN 20
      ELSE 40
    END +
    --  千粒重（g）：适中为佳（[TGW_T2]~[TGW_T3]g），兼顾粒重与穗数
    CASE
      WHEN `千粒重` BETWEEN [TGW_T2] AND [TGW_T3] THEN 0
      WHEN `千粒重` BETWEEN [TGW_T1] AND [TGW_T4] THEN 10
      ELSE 20
    END +
    --  株高（cm）：适中为宜（[HEIGHT_T2]~[HEIGHT_T3]cm），利于抗倒
    CASE
      WHEN `株高` BETWEEN [HEIGHT_T2] AND [HEIGHT_T3] THEN 0
      WHEN `株高` BETWEEN [HEIGHT_T1] AND [HEIGHT_T4] THEN 10
      ELSE 20
    END +
    --  谷粒长宽比：“窄”为优质籼米特征
    CASE
      WHEN `谷粒长宽比` = '窄' THEN 0
      WHEN `谷粒长宽比` = '长' THEN 10
      WHEN `谷粒长宽比` = '中' THEN 20
      WHEN `谷粒长宽比` = '宽' THEN 30
      ELSE 20
    END +
    --  籼粳亚种：必须为“籼”或“籼粳中间”
    CASE
      WHEN `籼粳亚种` = '籼' THEN 0
      WHEN `籼粳亚种` = '籼粳中间' THEN 10
      ELSE 50
    END +
      --  NULL 值惩罚（关键性状缺失）
    CASE WHEN `全生育期` IS NULL THEN 100 ELSE 0 END +
    CASE WHEN `有效穗数` IS NULL THEN 100 ELSE 0 END +
    CASE WHEN `结实率` IS NULL THEN 100 ELSE 0 END +
    CASE WHEN `千粒重` IS NULL THEN 100 ELSE 0 END
  ) AS early_indica_rice_score
FROM <TABLE>
WHERE
  `籼粳亚种` IN ('籼', '籼粳中间')                  --  必须为籼稻类型
  AND `全生育期` BETWEEN [DURATION_T1] AND [DURATION_T4]             --  适应双季稻周期
ORDER BY early_indica_rice_score ASC
LIMIT 5;

- “窄长粒”“细长形”是优质籼米（如丝苗米、香米）的核心外观特征；
- 高产组合通常表现为“多穗 + 大穗 + 高结实率”的协同；

③【综合评分与排序逻辑】

数值型性状采用 区间打分法（最优区间得0分，偏离越大得分越高）；
枚举型性状按 优劣顺序映射分值（如“圆筒形”=0，“分裂柱”=30）；

明显劣质值加高惩罚（如千粒重 < [TGW_T1]g 加 80 分）；

SELECT
  `全国统一编号`,
  `种质名称`,
  `生育日数`,
  `株高`,
  `穗位高`,
  `穗长`,
  `穗粗`,
  `千粒重`,
  `粗蛋白`,
  `粗脂肪`,
  `粗总淀粉`,
  `粒型`,
  `穗形`,
  `原产国`,
  `原产地`,
  (
    --  千粒重（g）：≥[TGW_T3]g 为高产大粒型
    CASE
      WHEN `千粒重` >= [TGW_T3] THEN 0
      WHEN `千粒重` >= [TGW_T2] THEN 10
      WHEN `千粒重` >= [TGW_T1] THEN 20
      ELSE 40
    END +
    --  穗长（cm）：≥[SPIKE_LENGTH_T3]cm 为大穗型
    CASE
      WHEN `穗长` >= [SPIKE_LENGTH_T3] THEN 0
      WHEN `穗长` >= [SPIKE_LENGTH_T2] THEN 10
      WHEN `穗长` >= [SPIKE_LENGTH_T1] THEN 20
      ELSE 30
    END +
    --  穗粗（cm）：≥[EAR_DIAMETER_T2]cm 为粗穗，利于高粒重
    CASE
      WHEN `穗粗` >= [EAR_DIAMETER_T2] THEN 0
      WHEN `穗粗` >= [EAR_DIAMETER_T1] THEN 10
      ELSE 20
    END +
    --  粒型：“马齿型”产量高，饲料首选
    CASE
      WHEN `粒型` LIKE '%马齿%' THEN 0
      WHEN `粒型` = '半马齿' THEN 10
      WHEN `粒型` = '硬粒' THEN 20
      WHEN `粒型` LIKE '%甜%' OR `粒型` LIKE '%糯%' THEN 50
      ELSE 30
    END +
    --  穗形：“圆筒形”“柱形”优于“锥形”
    CASE
      WHEN `穗形` LIKE '%圆筒%' OR `穗形` LIKE '%柱形%' THEN 0
      WHEN `穗形` LIKE '%柱%' THEN 10
      WHEN `穗形` LIKE '%锥%' THEN 20
      WHEN `穗形` LIKE '%分裂%' THEN 40
      ELSE 30
    END +
    --  株高（cm）：适中为宜（[HEIGHT_T2]~[HEIGHT_T3]cm），过高易倒伏
    CASE
      WHEN `株高` BETWEEN [HEIGHT_T2] AND [HEIGHT_T3] THEN 0
      WHEN `株高` BETWEEN [HEIGHT_T1] AND [HEIGHT_T4] THEN 10
      ELSE 20
    END +
    --  穗位高（cm）：适中（[EAR_HEIGHT_T2]~[EAR_HEIGHT_T3]cm）利于抗倒与收获
    CASE
      WHEN `穗位高` BETWEEN [EAR_HEIGHT_T2] AND [EAR_HEIGHT_T3] THEN 0
      WHEN `穗位高` BETWEEN [EAR_HEIGHT_T1] AND [EAR_HEIGHT_T4] THEN 10
      ELSE 20
    END +
    --  粗蛋白（%）：饲料玉米 ≥[PROTEIN_T2]% 为优
    CASE
      WHEN `粗蛋白` >= [PROTEIN_T3] THEN 0
      WHEN `粗蛋白` >= [PROTEIN_T2] THEN 10
      WHEN `粗蛋白` >= [PROTEIN_T1] THEN 20
      ELSE 30
    END +
    --  生育日数（天）：匹配黄淮海光热周期（[DURATION_T2]~[DURATION_T6]天）
    CASE
      WHEN `生育日数` BETWEEN [DURATION_T2] AND [DURATION_T6] THEN 0
      WHEN `生育日数` BETWEEN [DURATION_T1] AND [DURATION_T7] THEN 10
      ELSE 20
    END +
    --  NULL 值惩罚（关键性状缺失）
    CASE WHEN `千粒重` IS NULL THEN 100 ELSE 0 END +
    CASE WHEN `穗长` IS NULL THEN 100 ELSE 0 END +
    CASE WHEN `生育日数` IS NULL THEN 100 ELSE 0 END +
    CASE WHEN `粗蛋白` IS NULL THEN 100 ELSE 0 END
  ) AS high_yield_feed_corn_score
FROM <TABLE>
WHERE
  `生育日数` BETWEEN [DURATION_T1] AND [DURATION_T7]                        --  适应黄淮海主产区
  AND `株高` <= [HEIGHT_T5]                                  --  控制倒伏风险
ORDER BY high_yield_feed_corn_score ASC
LIMIT 5;

③【综合评分与排序逻辑】
当用户任务为抽象目标（如“高蛋白食用大豆”“高油压榨型”“机械化种植专用品种”），需设计综合评分模型 total_score：
硬性条件：根据用户目标设定关键阈值（如粗蛋白 > [PROTEIN_T2]%、百粒重 > [HSW_T2]g），不满足则直接过滤；

生成 SQL：先 WHERE 过滤硬性条件，再对关键性状打分加权求和；
所有目标字段按重要性赋权并加和，得分越低表示越优；
数值型性状采用 区间打分法（最优区间得0分，偏离越大得分越高）；
枚举型性状按 优劣顺序映射分值（如“有限”=0，“无限”=20）；
NULL 值施加惩罚：核心品质性状（粗蛋白、粗脂肪、百粒重）缺失惩罚 100 分，其他农艺性状缺失惩罚 60 分；
明显劣质值加高惩罚（如粗蛋白 < [PROTEIN_T1]% 加 80 分）；
最终按 total_score ASC 排序，返回最多5条优质种质。
