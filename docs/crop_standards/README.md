# Crop Descriptor Standards: English Translations

This directory provides author-prepared English translations of crop-specific descriptor standards for the five crops covered by CGR-Bench. They help readers understand the trait definitions, measurement units, and evaluation scales used to configure knowledge-enhanced retrieval in CropMaestro.

## Documents

- [Barley — Specifications for the Description of Barley Germplasm Resources](english/barley.pdf)
- [Maize — Specifications for the Description of Maize Germplasm Resources](english/maize.pdf)
- [Rice — Specifications for the Description of Rice Germplasm Resources](english/rice.pdf)
- [Soybean — Specifications for the Description of Soybean Germplasm Resources](english/soybean.pdf)
- [Wheat — Specifications for the Description of Wheat Germplasm Resources](english/wheat.pdf)

## Source and translation

The original Chinese crop descriptor standards are provided through the [National Crop Germplasm Resources Sharing Platform](https://ncgrip.cgris.net/web/standard), subject to the platform's access arrangements. The source documents identify the National Crop Germplasm Resource Platform and the National Crop Science Data Center.

The English PDFs are reference translations supplied by the CropMaestro authors to make the crop-specific standards accessible to international readers. They are not official English editions issued by the source platform. Consult the original Chinese documents for authoritative wording.

For the benchmark queries and reference annotations, see [CGR-Bench](../../cgr_bench/). For instructions on preparing a data source for the released workflows, see the [workflow setup guide](../setup.md).
